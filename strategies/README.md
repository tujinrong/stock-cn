# 策略编号总表（讨论草案）

当前编号规则：

- **A系列**：现有5股组合动态管理。
- **B系列**：备用，暂不定义策略。
- **C系列以后**：其他策略。
- 一个系列可以包含多只股票；不再按“一只股票一个系列”设计。
- 每个正式策略默认独立20万元模拟资金；同系列变体用于对照，不自动增加正式资金。
- 当前全部仍为DRAFT/RESERVED，尚未启动正式模拟。

C系列当前股票池先使用同样5只股票，但从100%现金开始，由AI决定是否买入、买哪只、买多少：

## 共同规则

所有策略均继承 [common.md](common.md) 和根目录 [AGENTS.md](../AGENTS.md)：

- A股范围排除科创板；
- 不做日内短线；
- 每策略每交易日最多一次正式决策、至多一笔买入或卖出；
- 正式执行使用当时真实可得的行情、财务、公告、新闻等资料；
- 历史测试与正式账本隔离；
- 不使用数据库，策略、提示词、交易和模拟结果使用GitHub文件管理；
- 策略可以在用户确认后向前微调，不追改历史。

提示词入口位于各系列的 `prompt.md` 与 `variants/` 文件中。旧编号内容可通过Git历史追溯，不再属于当前策略表。

未来新增方案可以继续使用 **G、H、I……**，不需要重排现有编号。
