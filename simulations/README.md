# 调试与历史模拟文件

**目前尚未执行测试，本目录没有模拟账户或回测成绩。**

每次用户实际要求测试时创建独立 <test_id>/，可包含A01、A02等平行变体和临时策略。各自有prompt快照、连续账户、事件与逐日结果；manifest记录区间、虚拟时点、数据来源/缺口和资金口径。

允许盘外回放几天、几周或两个月，尽量调取真实历史行情、当时公开的财务与新闻。同策略每天依次推进，不同策略/变体可并发，不能把同一账户的各天无依赖并行。

测试默认各变体独立20万元虚拟起点，不计为正式追加资金。优先真实资料，缺分钟或历史公告时披露近似口径；合成数据只能用于明确标注的TEST_ONLY流程测试。

summary.md显示实际完成范围、净收益、回撤、费用及限制。结果未完成不能声称完整回放；微调重跑新建test_id保留旧结果，不混入正式净值。临时策略不自动进入正式策略目录，但保留解释结果所需最小提示词快照。

详见 [file-layout](../docs/file-layout.md)。
