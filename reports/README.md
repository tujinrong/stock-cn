# 收益与比较报告

**目前没有运行记录，因此没有已生成的收益或排名。**

未来 daily/YYYY-MM-DD.md汇总各策略当天动作和净值；performance/<report_id>/包含区间report.md及metrics.json；exports/<report_id>/提供equity.csv与trades.csv便于阅读。

报告从已提交账本生成，不是另一套权威余额。记录数据截止、实际覆盖天数、估值是否暂估、来源和版本。正式净值、调试与历史回放分别报告，失败和未运行不能假装正常持有。

评价整个账户的扣费净收益、浮动盈亏、最大日频回撤、交易次数、费用与现金比例；可加入明确口径的固定股票买入持有或其他基准。资金隔离，对照变体不能当作正式多份出资，部分样本不冒充完整两个月。

经确认的策略微调标出生效点但保留连续净值，不直接把阶段差异解释为修改的因果效果。详见 [file-layout](../docs/file-layout.md)。
