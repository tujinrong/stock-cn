# 独立变体、完整提示词与历史时点隔离

## 执行单位

A/B/C等系列只分类，A01、A02等每个变体是独立账户与任务。每变体默认20万元模拟总资产；A各变体均以五股合计75%加25%现金的相同假定期初开始，其他变体从现金开始。不是共用一个系列账户。全部正式账户仍未初始化、未启用。

```text
strategies/A/variants/A02/
  prompt.md                    # 该变体完整基线提示词，可独立阅读
  init.json                    # 该变体初始化计划
  holdings.json                # 该变体正式模拟持仓，尚未初始化
  holdings.md
  simulation_prompt.json       # 新测试所用的完整提示词版本
  improvement_state.json       # 持久改进计数，硬上限10
  prompt_versions/v000.md       # 初始完整版本
  prompt_versions/v001.md       # 验证通过后保留的完整候选
  improvements/round-01/        # 原文、候选、反馈、验证和结果
  simulations/<test_id>/       # 独立测试持仓、实际AI输入、决定、执行及日结
```

源系列模板与原variants/A02.md只保留为设计来源。迁移时一次性展开为该变体的完整文件，实际运行不再读共用系列模板来拼接投资意图。每日只注入该变体当前日期、资金、现金、各股股数/可卖量、前次理由及当时可知证据。

## 改进最多10轮

每变体独立计数，基线v000不计一轮；每次提出候选前预占一次。失败、拒绝和中断也计数。重启或重新命名批次不重置。第11次不会调用改进器，需用户明确开启新的改进周期才可另行设计重置。

改进目标为格式、证据时间、账户身份、缺资料处理和指令清晰度的稳定性，不按回测结束收益自动修改买卖倾向或风险承受度。投资意图与硬约束有不可自动修改区块。保留每轮完整旧新文本，不只保留摘要。

验证通过的候选只更新新隔离模拟所用版本，不自动修改正式批准的提示词。已开始的回放固定输入版本；新候选需新test_id对照，不覆盖旧结果或向过去补单。通过就提前停止，无须凑满10轮。

本轮的A02改进演示只验证提示词结构/契约；没有调用付费模型，也没有证明真实AI多次运行的统计稳定性。真正的模型改进器可通过PromptLab的proposer/evaluator接口接入，须按同样的计数和范围约束。

## 不知道接下来发生什么

模拟每天视自己位于信息截止时刻。只提供此前完成价格、当时已公开财务/公告/新闻和前一天的账户；后续价格、后来新闻、最终收益、后验赢家不得进入当天输入或提示词改进反馈。

程序增加“相同已知历史前缀不变性”测试：任意改变之后的价格与新闻，当前生成的完整AI输入仍必须相同。全数据校验指纹仅在记账元数据中，不把包含未来数据的指纹传给模型；对外输入指纹仅基于已知前缀。

来源已知时间晚于截止点的证券不进入当前研究输入。资料不足返回INSUFFICIENT_DATA，不强迫AI修成READY/HOLD；不消耗交易额度或编造成交。模型预训练可能含后续事件，因此不能声称绝对消除前视偏差。

现有日线回放仍是前收盘判断、次日开盘代理执行，不能冒充11点盘中回放。缺历史财务/新闻或成交规则元数据的测试仍须明确标为流程测试。


selfcheck使用显式TEST_ONLY合成数据与脚本答复，验证流程，不代表真实AI选股收益。真实AI仍通过文件式答复或另行授权的适配器；测试与正式文件隔离。GitHub工作流仅运行代码验证，不是每天自动投资任务。
