# 统一绩效出口与本次续测

连续模拟的 report.json/report.md 与批次 summary.md 共用绩效口径：账户现金加持仓收盘市值、净收益、实际已完成交易日复合年化、日频最大回撤、成交数、期初组合HOLD/现金基准与超额收益（收益率相减的百分点）。未完成窗口只按已完成天数换算，零天不年化；亏损100%的年化为-100%。

胜率按FIFO将本轮买入与已完成卖单配对，扣除两边费用；部分卖出按卖单计算。假定期初持股没有可靠历史成本，相关卖单不计胜率。没有可配对卖单时为空，不用上涨天数代替。
