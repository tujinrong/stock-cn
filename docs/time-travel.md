# AI时光穿越历史模拟

## 目的

在不修改策略正文的前提下，让同一份完整变体提示词“回到”某个历史时点，用当时可见的价位、市场状态、行业结构背景和多周期K线做大致判断。

新闻、媒体文章等难以准确回退的内容默认忽略。没有新闻不代表当时没有风险；系统不会补造历史新闻。

## 两种运行方式

### 单点跳转

适合“我要回到X年Y月Z日看看当时会怎么判断”。

系统在X日收盘时建立一个**隔离的时光穿越期初账户**：A类已有持仓策略按X日收盘价和初始化权重建立大致持股，现金策略保持全现金。只记一笔OPENING_BALANCE，不伪造X日之前的买卖、手续费或收益。然后生成AI输入，若有交易建议，下一交易日开盘代理执行。

### 连续回放

适合评价一段时间的策略表现。从测试起点逐个交易日推进，前一天账户延续到下一天，不允许跳日。连续回放和单点跳转不能混成一条收益曲线。

## 日线模式的时间含义

当前MVP采用日线，因此：

- 用户指定“回到 X 日”；
- AI被放在 **X日收盘时**；
- 只提供X日及以前的未复权历史价格和可回退资料；
- AI不知道X日之后任何走势；
- 若决定交易，下一交易日开盘价作为Paper Trading代理成交价；
- 下一交易日收盘用于估值；
- 这不是历史11:00分钟级重演。

如果以后取得可靠历史分钟数据，可新增盘中时光穿越适配器，但不能用当日收盘价冒充当时盘中价。

## 同一提示词

每个变体仍使用自己的完整 prompt.md / prompt_versions 版本。时光穿越不会另建“回测策略提示词”，只在本次AI输入末尾增加运行时段落：

“你现在回到 YYYY-MM-DD 收盘时……你不知道之后发生的任何变化……”

运行时段落包含：

- target_date / knowledge_cutoff / planned_execution_date；
- 当前可见股票的当时收盘价；
- 最近5/20/60交易日收益；
- MA5/MA20/MA60；
- 20/60/120/250交易日价格区间位置（有多少历史就用多少，不足则为空/有限样本）；
- 近20根日K；
- 近12根周K；
- 近12根月K；
- 近似年化波动；
- 股票所属行业及结构性行业特点；
- 股票池等权行情代理（没有真实大盘指数时明确标记为proxy）；
- 数据缺口和新闻忽略策略。

结构性行业特点只是长期背景，不代表当日新闻或行业观点。

## 防止偷看未来

time_travel.py只读取 knowledge_cutoff 以前的 bars。

回归测试要求：

1. 任意修改目标日之后的OHLCV，目标日生成的time-travel context完全不变；
2. 加入未来新闻，context不变；
3. 同一已知历史前缀生成的完整AI提示词不变；
4. 日/周/月K线的最后日期不能晚于knowledge_cutoff；
5. 时光穿越默认不把历史新闻作为必要输入；
6. 模拟仍使用独立账户和同一paper_core，不影响正式账户。

模型训练本身可能含有后来知识，因此仍只能说“最大限度做点时模拟”，不能声称绝对消除前视偏差。

## 使用

先准备真实历史日线到仓库外文件：

    python -m stock_cn.sim_cli probe --test-id source-tt-001 --start 2025-01-01 --end 2025-12-31 --output /tmp/history.json

生成“回到2025-08-01收盘时”的完整AI输入：

    python -m stock_cn.sim_cli time-travel --test-id tt-001 --variant A02 --data /tmp/history.json --date 2025-08-01

输出会指出：

- ai_input：同一完整策略提示词 + 时光穿越运行层；
- time_travel_context：本次历史市场快照；
- planned_execution_date：下一交易日。

如果只取得部分历史，系统明确披露样本长度；不把不足250个交易日的数据伪装成完整一年。


## 验收要求

单点跳转必须能够从包含更早历史的长数据集中直接回到目标日，而不要求把起点到目标日逐日交易一遍。CI中的真实历史验证使用腾讯未复权日线，约覆盖2024-07-05至2025-08-08，再回到2025-08-01；要求至少200个历史交易日，并在数据足够时验证250日位置。该步骤是强制通过项，不允许失败后继续标绿。


## 权益事件和价格口径断点

未复权价格更接近真实成交价，但送股、转增、拆并股、除权除息可能制造看起来像“暴跌”的价格断层。

时光穿越会对相邻收盘价进行基础异常检查。普通主板单日原始收盘变化超过25%时，先标记为 `SUSPECTED_CORPORATE_ACTION_OR_DATA_BASIS_BREAK`，不能直接解释成经济意义上的涨跌。

断点出现后：

- 原始日K/周K/月K仍保留，便于人工查看；
- 收益率、MA和20/60/120/250日位置只使用最近断点之后的连续价格段；
- 连续样本不足时对应统计为null；
- AI提示词会看到断点信息，不应把它作为F类“异常下跌买点”；
- 真正跨权益事件的连续收益回测仍需要经验证的权益事件处理器，启发式断点保护不能替代完整公司行动数据。

真实历史验收中，比亚迪2025年7月送股/转增导致未复权价格出现显著断点，系统能够识别并停止跨断点计算20/60/250日指标。
