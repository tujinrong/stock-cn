# stock-cn

**意图驱动、GitHub纯文件记账的A股AI模拟辅助工具。** 策略不是固定买卖公式；AI决定研究与仓位，程序负责可靠的输入、校验和记录。

## 当前里程碑：研究证据链 + 锁定判断 + 延迟执行

已实现独立变体账户、完整提示词、时光穿越、全市场有限候选、官方公告/财务/新闻研究文件、AI判断锁定、未来结果隔离、延迟到真实下一交易日执行以及结算后的连续模拟续跑。正式Paper账户保持隔离；没有连接真实券商，也没有启用每日正式投资调度。

## 先运行无付费自检

```bash
python -m pip install -e ".[dev]"
python -m pytest -q
python -m stock_cn.sim_cli selfcheck --test-id smoke-001 --workers 2
```

自检使用**TEST_ONLY合成价格＋测试脚本回复**。它证明工程流程和资金计算是否符合测试，不证明AI策略盈利。真正AI参与用prepare生成输入、apply接收AI答复，或在单独授权后选择API适配器；见运行指南。

每个变体在strategies/<系列>/variants/<变体>/下拥有自己的prompt、FORMAL Paper持仓和simulations目录。研究任务、研究输入、锁定判断与延迟执行分别保存在research-*目录和runs/research*中；原始全市场行情不建库。

自动验证工作流运行单元测试及仓库实际提示词的多变体模拟，有限尝试历史日线主备源，并只提交模拟结果。没有日程触发器，也不调用付费模型。网络验收失败会单独记录，不能把其他测试通过说成数据源通过。

## 策略与资金

A为已有五股组合，A01稳健/A02均衡/A03进取；B备用；C固定股票池从现金择时；D年度低位回升；E业绩改善；F异常下跌回升。每系列计划20万元，平行变体测试不重复计算正式资金。

A初始目标五股各15%、现金25%，实际整数股取整余款留现金。其他系列现金起步。所有系列排除科创板，每个账户每个交易日最多一笔买入或卖出，也可以不动，不做日内短线。

## 当前真实联调

2026-10-03续测补齐连续模拟与历史点决策的统一绩效表、实际区间年化和扣费卖单胜率，新增D/E/F七变体2025-05-30历史时点评价。结果与限制见[统一比较](reports/performance/comparison.md)及[绩效口径与本次续测](docs/performance-comparison.md)。年化只是数学换算；缺资料的E03/F01保留未评分状态。正式提示词与账户保持隔离。

2026年A–E已完成12个现有变体、三个独立历史时点、原版与资金机会成本候选共72项真实AI锁定判断，54项可评分、18项资料不足；B仍为空。A03两段留出平均从−3.9603%改善到−3.6112%，属于减亏、仍未盈利；D01/E01候选更差，D02回撤增大，未自动提升任何默认或正式提示词。支持核实纯现金分红的点式权益估值、同日日期精度保护与无损压缩输入；294项回归通过。完整收益、年化、回撤、胜率空值、基准、超额与时间检查见[2026测试与改进报告](reports/performance/ae-2026.md)。这是独立点判断比较，不是全年逐日AI回放。

后续修复支持重复评分、成交事件保存后的中断恢复和评分窗口扩展，并冻结实验原费用。新闻覆盖按实际检查日标记，历史默认忽略的新闻正文不进入AI输入；旧日期快照不再计为当天核验。汇总区分尝试数量与真正完成评分的数量。

D02/F01已经用2026-09-30时点完成候选K线、CNINFO官方资料、AI财务/新闻研究、完整提示词和判断锁定。D02锁定为BUY恒瑞医药300股（约7.1%拟仓位），F01锁定为HOLD；截至2026-10-03检查真实数据时仍没有后续交易日，因此两者都保持WAITING，没有伪造成交。判断锁定后才允许未来执行数据进入结算层。

## 尚不能据此声称完成的内容

日线时光穿越不是严格历史11点逐笔回放；历史全市场选股仍有证券集合幸存者偏差。正式当前报价、交易日历和实时交叉核验还需要独立正式验收。特殊权益事件和更多证券规则仍需扩充。API适配器没有在未授权情况下调用付费模型。当前历史样本不足以证明两个月能稳定盈利，也没有连接真实券商。

原有stock-cn demo是旧离线均线演示，与新的AI模拟接口分开保留。

> 本项目只做模拟。测试收益不构成收益承诺，不保存真实券商账户、个人信息或密钥。
