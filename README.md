# stock-cn

通过自然语言对话设计和运行的 **A 股 AI 模拟投资研究工程**。

用户提出投资意图与边界，AI 自主研究、综合判断；程序提供数据读取、计算、交易校验、资金记账和结果保存工具。策略不要求先写成固定算法，AI 也不只是给固定算法生成说明文字。

项目协作与运行规范见 [AGENTS.md](AGENTS.md)。修改策略或执行模拟前应先读取该文件及对应策略任务书。

## 当前确定的设计

- 支持 N 个独立策略，每个策略初始模拟资金 **200,000 元人民币**，各自保留现金、持仓与收益记录。
- 策略有用户逐步确认的 1–5 个参数变体，可包含数值或定性的分析偏好。正式模拟默认每策略选择一个变体；切换不重置账户。
- **固定股票 FIXED**：只在指定股票中判断买卖时机。**自选股票 AI_SELECT**：AI 在约定市场范围或股票池内选择机会。
- 当前意图方向包括“寻找一年周期内较优购买时机的股票”和“寻找指定股票的较优买卖时机”。这些是待讨论的方向，不是已启动策略，也不保证事先找到全年最低价或最高价。
- **每策略每交易日最多一次正式决策、至多一笔买入或卖出，也可以不操作**。不是买一次加卖一次，不在同日内反复调仓，不依赖盘中监控或日内短线。
- 需求对话、调试、模拟运行、正式执行四种模式隔离。调试可在盘外进行；正式模拟只在有效交易时段读取实际数据并判断。
- 原始行情按需读取，暂不建立本地行情库。保留必要的模拟成交、决策、账户状态、每日估值与净值，按一段时间评估扣费后的收益和回撤。
- 未来可以另行配置每日定时触发，例如中国市场时间 11:00；目前仅记录设计意图，**没有因此创建定时任务**。

## 当前实现与设计目标的区别

现有 Python 代码是离线基础演示，包含账户、简化交易规则、模拟撮合、均线策略、规则分析器占位、模拟引擎、命令行和测试文件。

**AGENTS.md 中的 AI 自主决策、真实行情读取、每日一次的持久防重复校验、多策略正式账户与日结留存，是当前规范；不能仅因文档存在就声称这些运行能力已经实现。**

现有 `RuleBasedAIAnalyst` 是规则占位实现，不是真正的自主研究模型。均线示例不是后续策略必须遵循的研究方式。项目目前不连接真实券商账户。

演示版交易约束与费用处理是简化实现，正式模拟前还需按适用证券和交易日期完善及验证。不要把演示生成的行情、成交或收益当作实际市场记录。

## 运行离线演示

需要 Python 3.11+。

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate

pip install -e ".[dev]"
stock-cn demo --cash 200000
pytest
```

上述命令只运行离线演示，并不建立持久的正式策略账户，不触发真实行情研究，也不创建每日任务。

## 后续按对话逐步落实

先与用户明确各策略的意图、范围、变体和自主权限，再按需要提供通用取数与计算工具。优先实现账户状态恢复、每日一次防重复、交易时段校验和轻量结果保存，不以先建设本地行情数据库或固定评分流程为前提。

正式模拟需要把 BUY、SELL、HOLD 决策与有效模拟成交区分，保存交易及不交易的结果，使用连续账户计算阶段表现；不得把盘外调试或事后回放混入正式实绩。

> 本项目用于研究与模拟，不构成收益承诺。本轮仅更新规范与说明，未启动正式策略、定时运行或真实交易。
