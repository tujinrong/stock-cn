# 批次与后台异步任务

目标是一次触发多个已授权策略，独立研究、独立结束、统一汇总。**目前仅有设计说明，未部署执行器、创建定时任务或启动任何后台运行。**

未来每批次 <batch_id>/manifest.json 记录模式、策略/变体、信息截止时点、prompt版本与预算；jobs/<job_id>/status.json保存状态及结果引用，attempts/保存失败与重试记录。summary.md汇总完成、失败、跳过、取消，不能把缺失结果写成HOLD。

不同策略/隔离测试变体可并发；同一正式账户和历史测试虚拟日期必须按顺序。公共资料只读复用不得跨越历史信息边界。一个任务失败不拖住其他独立任务。

分析可以并行，账本由统一提交协调者验证后有序提交，避免覆盖、重复成交与旧版本写入。状态文件本身不是锁也不是成交证据；已提交正式或模拟events才是事实依据。

并发数、超时、调度时间、外部执行器、数据/模型费用仍需后续验收及必要授权。每天11点是未来例子，目录存在不代表后台会自动运行。详见 [file-layout](../docs/file-layout.md)。
